# Class presentation, 24 September 2026

The slides for Group 1's Week 9 class presentation, as they were shown.

Open `index.html` in a browser. There is no build step and nothing is fetched from the internet: the fonts, the images and the demo video are all in `assets/`.

| Key | |
|---|---|
| Right arrow, or click the right side | next slide |
| Left arrow, or click the left side | previous slide |
| F | full screen |
| Space | on slide 4, plays and pauses the demo video |

`script.md` is what was said on each slide, with the time each one takes and who says it.

`assets/demo.mp4` is stored with Git LFS. On a clone without git-lfs it is a small pointer file, and slide 4 shows only the poster frame: install git-lfs and run `git lfs pull`.

Everything on screen is synthetic. No real person, account number or amount appears in it.
