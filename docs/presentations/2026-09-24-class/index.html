Eval · variables

An experiment may change five things

1Letterswhich ones are read
2Modelwhich model, at which reasoning effort
3Promptwhat the model is told
4Repeatshow many times each read is repeated
5Schemehow the reads are combined into one answer  ·  the breakthrough

Seven experiments so far. Everything else is held the same, so when two runs disagree the reason is one of these five.
